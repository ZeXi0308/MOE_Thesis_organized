# Fresh 与低负载输出 token 模式诊断

**短周期重复在较低压力下仍大量存在，降低到达速率没有消除该模式。** 全部六格 fresh 中，每格 **35–42/128** 个输出含至少 512 token 的短周期连续重复；全部四格低负载中仍为 **36–41/128**。低负载四格均 0 抢占、两格退休均 0 超完整上界准入，却每格仍有 **3 个同一 token 连续输出 1,024 次**的请求。这限制了工作负载代表性，不能把服务 goodput 解读为有用内容 goodput。

## 范围与固定判据

直接导入原有 [longest_short_period](C_SUSTAINED_TOKEN_PATTERN_DIAGNOSTIC.py)，不改算法或阈值：周期 **1–16 token ID**，至少重复两次，统计最长连续重复跨度 **≥512 token**；“恒定 1,024”要求整个输出恰为 1,024 个相同 ID。判据沿用此前 posthoc 诊断，不是新设定的确认性质量标准。[旧诊断](C_SUSTAINED_TOKEN_PATTERN_DIAGNOSTIC_20261001.md)覆盖此前八格 sustained 运行，未覆盖这里的十格。

本次纳入 fresh **全部六格**与低负载 **全部四格**；另将后来单次 donor 格完整列出，不作负载配对。11 格每格 128 请求均完成，request ID、document ID、prompt token 哈希与长度全部对齐。低负载是同一到达抽样时间乘 5，文章、生成 cap=1,024 和自然 EOS 配置保持原设定。诊断只读取原始输出，不删请求、不改原始指标、不启动 GPU。

Fresh 汇总为 **228/768（29.69%）** 次输出达到 ≥512 重复、18 次恒定 1,024，length/stop 合计 **726/42**；低负载为 **153/512（29.88%）**、12 次恒定 1,024，length/stop 合计 **487/25**。两组总输出分别为 745,514 / 499,787 token。这些是相同 128 篇文章多次执行的描述性计数，策略构成和重复数也不同，不能当作独立样本发生率或质量无变化的统计证明。`stop` 沿用原始自然终止分类。

11 格中所有达到 ≥512 重复的输出均以 `length` 结束；所有恒定输出恰为 **token ID 426 重复 1,024 次**，没有更短的全恒定输出。该 ID 的已有固定 tokenizer 解码说明见旧诊断，本次没有新增语义打分。

## 同策略跨负载的逐请求变化

“保留 / 消失 / 新增”按相同文章 ID 从 fresh 到低负载计算，描述固定编号的同策略执行，不视为独立匹配因果实验。完整 128 项差值、所有转移 ID 和 11 格模式矩阵保存在 [JSON](fresh_lowload_token_pattern_v1.json)。

有 **22 篇文章**在全部十个主比较格中都达到 ≥512 重复。低负载四格共有 34 篇持续命中、43 篇至少命中一次。以下 ID 例子显示模式的持续与双向变化，全部 ID 均保留在 JSON，未据此选择或排除请求：

- `memory-train-article-0124796`、`memory-train-article-0140901`：十格及 donor 均为 ID 426 × 1,024。
- `memory-train-article-0142615`：fresh 原生 1 / 退休 2 最长短周期跨度仅 3 token；其余 fresh 四格及全部低负载四格均为 ID 426 × 1,024。低负载没有统一改善该模式。
- `memory-train-article-0133176`：fresh 两格原生均为 ID 426 × 1,024；fresh FIFO/退休、全部低负载及 donor 均为 30 token 后 `stop`，最长短周期跨度为 3 token。单个请求模式消失可以同时改变工作量和结束方式。

## 可支持的结论与限制

本次直接回答的是**较低压力下是否仍有相同 token 模式**：有，而且低负载四格都保留该现象。它排除了“这些重复只会伴随本块所见原生抢占或超上界准入而出现”的解释；不能据此断言压力完全无影响，或定位模型、输入任务格式、数值执行与调度各自的原因。

[固定模型 revision 的官方 README](https://huggingface.co/allenai/OLMoE-1B-7B-0924/blob/6d84c48581ece794365f2b8e9cfb043c68ade9c5/README.md)的 Use 示例直接对普通续写输入 `Bitcoin is` 分词；该版本为 annealed base，SFT/Instruct 模型另行链接。配套本地 `tokenizer_config` 的 `add_bos_token`、`add_eos_token` 均为 false，且无 `chat_template`。因此缺少 chat template 本身不是已证实的接入错误；这些事实也不证明整篇文章续写具有代表性，或隔离了重复的原因。

同一已看过 cohort、时间分离的重复、到达倍率带来的并发与 batch 变化、输出轨迹变化共同限制因果解释。未命中本判据也不表示输出有意义，命中也不是独立的语义质量评分；短于 512 的重复没有被本阈值计入。现有原生服务成本结果继续描述这个具体工作负载，不能升级为有用输出收益，也不通过事后过滤重算 goodput。保持控制器不变，下一步由固定模型与输入格式检查定位工作负载有效性限制。
