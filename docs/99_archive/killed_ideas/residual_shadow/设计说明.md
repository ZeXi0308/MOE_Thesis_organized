# 名称

Residual-EP 与 Tiered-Fidelity Shadow Experts（共享基座残差通信 与 拥塞时低秩影子专家）

## 1. 背景与问题

这是两个共享同一必要条件、被同一轮免训练 SVD 实验一起判死的候选：
- **Residual-EP**：假设 MoE 专家权重之间存在共性，若减去一个共享基座（如逐层专家权重的均值），剩下的 residual `Δ_e = W_e − B` 会比原始专家权重更"低秩"/更小动态范围，因此远端通信可以只传输更紧凑的 residual 而不是完整 expert output，本地用共享基座算，远端只需处理残差。
- **Tiered-Fidelity Shadow Experts**：假设在拥塞时，可以用本地的低秩/蒸馏"影子专家"（shadow expert）替代远端完整专家的计算，牺牲一定精度换取避免远端通信/等待。

两者原本被认为需要训练（微调或蒸馏）才能得到本地代理，因而被评估为"最容易超出毕设时间预算"的方向，在选题地图阶段被搁置为"未推进"，从未真正写过一行代码。2026-07-20 的后续任务用免训练的截断 SVD 给两者都构造了最廉价可能的本地代理，从而不需要任何训练成本就能检验两者共同依赖的必要条件。此外，`residual_shadow` 目录下还包含一个独立的探索性脚本 `run_temporal_residual_ep_p0.py`（时序/自回归相关性探索），它不是这两个候选主 verdict 的依据，只是一次相关的辅助探索。

## 2. 核心思想 / 机制主张

- **Shadow 模式（对应 Tiered-Fidelity）**：每个专家的 3 个权重矩阵（`gate_proj`/`up_proj`/`down_proj`）独立替换为各自的 rank-r 截断 SVD 重建——纯粹"本地跑一份压缩后的同一专家副本"，完全没有远端通信，代价是近似误差。
- **Residual 模式（对应 Residual-EP）**：先用同层所有专家权重矩阵的逐元素均值 B 作为共享基座，从每个专家权重中减去 B 得到残差 `Δ_e = W_e − B`，再对残差做 rank-r 截断 SVD 压缩；重建 = B + lowrank(Δ_e)。这直接检验论文前提——"残差比原始专家权重具有更小的有效秩/动态范围"，这是 Residual-EP 通信节省主张成立的必要条件。
- 两种模式共享同一组 rank fraction 扫描（0.05/0.10/0.25/0.50）和同一套下游 KL 评测方法（与 PLTB/layer_budget 完全一致的 paired bootstrap），使结果落在与项目其他候选相同的证据尺度上。

## 3. 实验如何设计

- **必要条件检验（先于质量测试）**：对真实 OLMoE 权重做免训练 SVD，直接比较残差 `Δ_e` 与原始专家权重 `W_e` 各自的 90% 能量有效秩，检验 Residual-EP 的核心前提"减去共享基座后残差更低秩"是否成立——这是一个几行代码几分钟就能跑完的检验，独立于任何端到端质量实验。
- **质量-压缩前沿**：在 OLMoE 全 16 层×64 专家×16 篇 sealed 文档上，对 shadow 和 residual 两种模式分别跑完整 rank 扫描（0.05/0.10/0.25/0.50），用与 PLTB/layer_budget 完全一致的方法测下游真实 logits KL（paired bootstrap 95% CI），对比两种模式在同一 rank 档位上的 KL 是否有统计差异（检验"共享基座"这个额外设计相对单纯 SVD 压缩是否有附加价值）。
- **辅助探索（`run_temporal_residual_ep_p0.py`，Mac，非主 verdict）**：检验连续自回归 token 位置是否足够频繁地重访同一专家，以及一种闭环残差表示（利用上一次同专家的输出做参考）在相同逻辑字节预算下是否比直接量化当前专家输出更准确——这是 stateful temporal-residual combine 通信的一个独立子假设，纯数值/逻辑字节实验，不测 GPU kernel、collective、NIC 流量或延迟。

## 4. 代码怎么组织（scripts/ 下文件角色）

- `run_tiered_fidelity_residual_svd_p0.py`：**主 verdict 脚本**，免训练截断 SVD 同时实现 shadow（本地低秩同专家副本）和 residual（共享基座+低秩残差）两种模式，跑必要条件检验（残差有效秩 vs 原始权重）和质量-压缩前沿（两种模式在同一 rank 档位上的下游 KL 对比），是 Tiered-Fidelity 和 Residual-EP 双双判死的直接证据来源。
- `run_temporal_residual_ep_p0.py`：**辅助/探索性脚本，非主 verdict 依据**，检验自回归连续 token 位置的专家重访频率，以及闭环残差表示相对直接量化的准确性优势，属于 Residual-EP 更广义主题下的一个独立、次要的时序假设探索。
- `test_temporal_residual_ep_p0.py`：对 `run_temporal_residual_ep_p0.py` 中编码逻辑（如"无重访时应退化为 FP8"）的单元测试。

## 5. 演进路径

Tiered-Fidelity Shadow Experts 与 Residual-EP 在 2026-07-13 选题地图阶段就被识别为"可能把论文拉向模型压缩""最容易超过本科毕设时间预算"的高风险方向，因而被搁置，从未真正投入实现——这是定性层面的担忧，没有实证支持。2026-07-20 的后续任务用免训练 SVD 给两者都构造了成本最低的可能实例，直接用真实数据检验其核心假设，属于"先测必要条件再决定是否值得投入训练成本"的策略性验证（本项目元模式八：检验必要条件比检验最终质量指标更省时间）。检验结果是决定性的负面：Residual-EP 的核心前提（残差更低秩）在真实权重上不成立，且两种模式的质量表现在统计上不可区分——这不仅证伪了 Residual-EP 特有的设计价值，也顺带确认了 Tiered-Fidelity Shadow 本身即便不考虑训练成本，免训练下限也远低于可用标准。这两条候选因而在从未投入蒸馏/微调成本的情况下就被决定性地排除，避免了投入原本被认为"工作量最大"的训练环节。

## 6. 判死结论与不要再怎么救

**两条候选双双 KILLED（决定性）**，且是必要条件层面的证伪，不是"效应量差一点没过门槛"：
- **Residual-EP**：残差 `Δ_e = W_e − mean(all experts)` 的 90% 能量有效秩与原始专家权重几乎完全相同（甚至略高）——`gate_proj`: 610.5→613.3，`down_proj`: 632.5→633.6，`up_proj`: 639.5→640.5（满维度均为 1024），`rank_reduction_frac` 全部为负值（-0.16%~-0.47%）。这直接证伪了论证核心前提"residual 的秩显著更小"；OLMoE 的专家权重矩阵在 90% 能量意义下接近满秩，本身就不适合低秩近似。且 shadow 与 residual 两种模式在每个 rank 档位上 KL 几乎完全重合（差异落在置信区间内），说明共享基座这个额外设计相对单纯 SVD 压缩没有任何附加价值。
- **Tiered-Fidelity Shadow Experts**：即便保留 50% 的秩（参数量减半），mean KL 仍高达约 0.60（95% CI [0.55, 0.66]）；rank=0.25 时 KL≈3.0；rank=0.05 时 KL≈8.0——已完全摧毁下游分布。对照本项目其他候选的 KL 门槛量级（`fixed_tail4/8`、PLTB 各 profile 通常在 0.005-0.05 区间，NLL_MARGIN 门槛为 0.005），即使是最保留秩（0.5）的最优点，KL 也比可接受阈值高一到两个量级。

**不要用更多免训练 SVD rank 网格抢救 mean-base 路线。** `SUPERSEDED`：「这不是训练能解决的表示能力问题」。现有证据只否定 `mean(all experts)` shared base + training-free truncated SVD；不能外推到 learned shared base 或 distilled shadow。后两者是新、昂贵且未验证的假设，不建议在当前论文时间窗重开，但不得写成已被本 P0 证伪。
