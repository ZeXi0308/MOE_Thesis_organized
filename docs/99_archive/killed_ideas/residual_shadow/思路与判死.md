# Residual-EP + Tiered-Fidelity Shadow · 思路与判死

## 机制假设

- **Residual**：共享基座本地算，远端只传 expert residual，且 residual **更低秩**。  
- **Shadow**：拥塞时用低秩/蒸馏 shadow 替代远端完整 expert。

## 检验门（先必要条件）

对真实权重做免训练 SVD：残差能量有效秩是否显著低于原始？Shadow 在可用 rank 下 KL 是否进入可服务区间？

## 判决

**KILLED（决定性）**。残差相对 mean-base **不降秩**（甚至略升）；shadow 在半参/更低下 KL 比项目其它机制高 1–2 个数量级。不外推到「训练 shared base / 蒸馏」——那是另一条工作量路径，本仓库未证明值得开。

## 不要再怎么救

不要先跑端到端再猜；压缩/分解类必须先测结构假设。
