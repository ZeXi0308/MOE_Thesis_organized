# MassCover-EP · 思路与判死

## 机制假设

用 gate/contribution / CVaR 证据决定专家副本跨故障域放置，压低故障时质量爆炸半径。

## 检验门

相对最强静态基线（gate_mass）CVaR 改善是否 ≥10%；更强算法是否还有空间。

## 判决

**KILLED / 无 knob 空间**。相对 gate_mass 仅约 4.7%–6.6%；`cvar_greedy` 已逼近 oracle，天花板本身不够。
