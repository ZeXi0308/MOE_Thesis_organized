# Expert Prefetch（系统）· 思路与判死

## 机制假设

跨层路由可预测 → 预取即将用到的 expert，掩盖 HBM 换页 / 加载。

## 检验门

1. 离线：transition 是否优于 frequency baseline？  
2. 系统：正确 `(layer, expert)` cache key + **full top-k** working set 下是否还有端到端收益？

## 判决

**系统 NO-GO**。离线信号可存在，但：原 cache 缺 `layer_id` 污染结果；full top-k 下工作集饱和（预测「该预取谁」无选择空间）；正确 key 下 transition 相对 frequency 几乎无增量。Novelty 亦被多篇 2024–2026 工作覆盖。

## 不要再怎么救

不要在同一 batch 设定下继续堆 predictor；若做 block splitting / 降 top-k，已是另一问题。
