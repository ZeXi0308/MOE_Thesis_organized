# PLTB / Additive-KL · 思路与判死

## 机制假设

- **PLTB**：层预算 / 冲突感知的动态尾部精度优于固定 fixed-tail。  
- **Additive-KL MILP**：用单层 KL 可加外推联合配置（曾被「3.77× 非可加」叙事杀掉）。

## 检验门

匹配语料与 offset 下 PLTB vs fixed-tail；additive 用 **增量** `Σ(KL_single−KL_fp8)` 而非重复累加 FP8 baseline。

## 判决

- Additive：**撤回「可加性已被证伪」**（3.77× 为双计伪影；增量 ratio≈1.08，CI 含 1）。**不**自动恢复 MILP 主线。  
- PLTB：匹配 `wikitext2_docs` 上 INT4/MXFP4 **仍不赢** fixed → `KILLED_MATCHED_DOCS_PROTOCOL`；仅撤回「一切切片从未赢过」的过度概括。

## 不要再怎么救

不要用旧 3.77× 写论文；不要把 additive 未决当成 PLTB 已活。
