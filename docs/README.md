# 文档导航

```text
docs/
├── current/          当前唯一权威状态
├── ideas/            按研究方向归档文档、代码和结果
├── meetings/         会议与汇报记录
└── archive/          已停止方向和非活动候选
```

## 阅读顺序

1. [当前研究状态](current/README.md)
2. [Idea 状态索引](ideas/README.md)
3. 进入对应 idea 目录阅读 `README.md`、设计文档、`experiments/` 和 `outputs/`
4. 需要追溯旧裁决或负结果时再看[归档](archive/README.md)
