# G64 T30/Q1 在途预填充资源检查修复资格

修复前同配置诊断实际捕获 free=86、target full-history need=86、native inflight reservation=132；异步加载的实际85块需求超过 free−reserved=-46，全部27个running请求被hold，无待处理传输。旧性能原件未记录该分支，不能倒推其精确现场值。

本资格只更换 LTR adapter 的 direct waiting admission 资源检查，保留计数/量子、保存/恢复后端、自然G64输入、模型、KV/host预算、预热和有界观察器。假说：当完整目标历史与原生在途保留无法共同容纳时，不获得或保留恢复target latch，允许原生已有工作推进，打断已定位的循环。检查只针对当前适配器资源合法性，不作为算法新贡献。

支持修复资格要求：真实guard拒绝被观察，64/64原请求完成且无诊断停滞触发；记录所有输出量、终止原因和失败，不与旧性能臂排速度。若guard仍卡住或资源不符则保留失败，不能继续参数校准。全局无饥饿、逐tensor正确性与性能优势不由此资格推得。成功后再冻结共同基线修订并继续原有界校准。
