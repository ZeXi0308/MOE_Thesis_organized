`load_serial(model, manifest_path, index_path, workspace, receipt_path, *, validate_loaded, fetch=urlopen)` is intended to be called once from a registered vLLM `BaseModelLoader.load_weights`. Install the existing WiSP adapter before model construction; retain vLLM's normal post-load processing afterward. The caller must supply the existing target-coverage validator, such as `DefaultModelLoader.track_weights_loading`. That validator checks target containers and can add postprocessed parameters; it does not replace this iterator's exact source-key and authenticated-shard checks. The helper requires a returned target-name set and raises on any failed check; initialization must then abort.

The iterator verifies immutable revision syntax, index SHA, unique JSON keys, exact shard coverage and each downloaded shard's bytes/SHA before yielding. It downloads into one exclusive private directory using plain HTTP response reads, so it does not create or delete HF blob/Xet cache entries. A tensor is cloned on CPU before being yielded to the single `model.load_weights(generator)` call. Once all tensors in that shard have been consumed, `safe_open` closes, then only that invocation's private shard is unlinked. The next download starts afterward. JSONL receipts preserve the metadata identity, per-shard bytes/hash, progress and final result. Receipt/output paths reject overwrite. Hash failures and early consumer termination close the generator and retain incomplete private shards with a failure receipt.

The clone is necessary: downstream iterators and views may retain the final yielded tensor across the next request for input. A direct mmap-backed yield would keep the file storage alive after unlink. Qwen's [vLLM 0.26 loading entry](https://raw.githubusercontent.com/vllm-project/vllm/v0.26.0/vllm/model_executor/models/qwen3_moe.py) accepts an iterable; the locally inspected `RoutedExperts._load_w13/_load_w2` end in `copy_`, and `AutoWeightsLoader` groups iterators without accumulating a complete checkpoint. No mapped tensor escapes this helper, even if a downstream clone/view remains live.
