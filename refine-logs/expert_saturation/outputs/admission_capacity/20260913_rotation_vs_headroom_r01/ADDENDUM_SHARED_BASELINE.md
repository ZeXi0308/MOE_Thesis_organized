# 共享基线与推演边界补充

2026-09-13。原 REPORT 与 raw 保留，本补充不新增 GPU 结果。

保 KV 的最新同动作实现已有[四项实测](../20260913_headroom_fast_r01/REPORT.md)：max-ITL 1.3867/1.3857s，吞吐相对同轮 native 为 −3.25%/−2.86%，平均完成 +7.61%/+7.23%。旧 checked 的 1.381s / 约 −3.9% 是历史参照。共享四臂采用 **headroom-fast** 并同轮重跑，不能把旧百分比当固定门槛。

轮转约 0.39s 是将原生步长套入假定缺席周期的推演；尚未包含动作改变后的批次、恢复期间增长、队列、调度税和完整完成时间。因此原报告中的“支配”只能描述所画的假设指标投影，不能解释为实测 Pareto 支配或已验证的系统贡献。吞吐维度也不能忽略：推演的 −3% 仍低于 native，且不同 cooldown 的吞吐不同。

原生的 122 步间隔、316 request-steps 总缺席，以及最大同时常驻需求超过池的算术，都不是轮转后的守恒结论。动作改变推进与完成释放后须重新测量。受影响请求数也不能单独保证 p50 不变；需要完整排序与共同执行的影响。

当前统一实验：`native32 / safe29 / headroom-fast / rotate32-c20`，正反序重复；比较吞吐、max-ITL、请求间隔与完成分布。仅胜过 safe29 或仅改善最坏值不足以建立贡献。轮转实现问题仍须修复，四臂 **UNRUN**。
