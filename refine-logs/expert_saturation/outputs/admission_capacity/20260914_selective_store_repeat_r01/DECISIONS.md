# 单次保存无指纹交错重复

只分辨同一已实现保存动作的完整请求代价，不增加动作/阈值/输入选择。前两臂动作前已有0.927s时间差，大于最终均完成差0.610s，因此净效果不明；首次保存前缀实际KV保真已获一格证据。该正确性证据不替代重复性能。

原selective_store_once pkg逐字节复用，无指纹/profiler/GC或观察器更改。单卡OLMoE BF16、旧32文档/3072+1024 ignoreEOS、50ms到达、6656 usable KV、token1024、cap32、native16GiB host connector，两臂都是相同受控328选择/329抢占，只差是否保存。不是完整轮转、不同新输入holdout或自然EOS。

固定顺序on/off/off/on四个新引擎，block0和block1各含一对，全部留存，不按结果重排或重跑。此前off/on仅历史诊断，单列不选择性合并。GPU共同flock覆盖整组，逐格现场检查，忙/查询失败/首失败即ABORT，不后台候卡或自动retry。

主观察为32条完整平均完成时间；同时报告wall、全体maxITL、逐请求完成差、目标恢复gap、重算/传输量、动作前时间差。逐对百分比和绝对差全部保留；动作前/后是会计分解，不扣除漂移制造校正收益。检查动作前调度与请求状态、后续独立演进及输出差异，异常保留。

本轮最多四格。两对完整平均完成同号且局部恢复方向一致只能是继续/代价信号，不是统计显著或方法GO；翻转或差异不能与运行漂移区分则保持UNRESOLVED，不加第三轮同域采样来追正。无论正负，不能判死KV恢复问题。结合完整代价判断是否值得推进状态触发的重复保存动作，需另行明确最强简单基线与完整等待代价。

CPU封存/未上传/GPU_UNRUN，不预留窗口。启动前重读共享协调；已准备streaming在认证恢复后的请求优先考虑，不假定本轮先跑。
