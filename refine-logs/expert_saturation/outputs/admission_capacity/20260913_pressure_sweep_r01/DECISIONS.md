## 研究问题（不变）

单卡固定显存下，怎样安排新请求入场与恢复，减少对已有 decode 的不成比例停顿，
同时保住有效服务量。本轮只控制**准入 + 恢复顺序**（轮转动作），其余固定。

## 本轮要回答的唯一问题

**轮转相对原生的优势，在结构赤字的哪个区间成立？**

现有全部证据只有一个工作点：赤字 521 块 = 2.035 个请求足迹。在该点轮转把
max-ITL 从 4.46 秒降到 1.01 秒，吞吐差小于已观测重复差。**一个点无法支撑
"这是一个机制"的主张**——它可能只是该点的巧合，也可能在更高压力下崩溃或更强。

## 新度量：步数 / max(L)

本轮采用一个绝对参照，取代此前的相对「尾部浪费」口径：

```
floor = max_i L_i          纯 decode 步数的下界
efficiency = 实测纯 decode 步数 / floor
```

依据：decode 逐 token 串行，需要 L 个 token 的请求至少占 L 个 step，
故全部同时入场时 episode 的纯 decode 步数不可能少于 `max_i L_i`。

该度量在已有数据上已给出干净排名（同 `max(L)=1024`）：

| 臂 | 步数/下界 |
|---|---:|
| rotate | **1.092** |
| native | 1.212 |
| headroom | 1.310 |
| safe29 | 1.913 |

它同时纠正了我上一轮的一处错误归因：异构负载的 23.6% wall 代价，
**106% 由 `max(L)` 由 2048 升到 3072 解释**，不是「宽度塌缩」这个独立原因；
两臂各自都跑在自身下界的 2.7–6.9% 以内。相应更正写入本轮报告。

## 预注册判据

阈值取自已有的**绝对**已观测重复差（`|Δwall| 0.2684 s`、`|Δmax-ITL| 0.2126 s`），
运行前给定。本轮另用自己同臂同压力的正反序差重算一份，两者都报告，
以更大者为准。**"大于已观测重复差"只表示可分辨，不表示统计显著。**

| # | 预测 | 证伪条件 |
|---|---|---|
| **P1** | D0 下两臂 max-ITL 差 < 重复差（无赤字→无抢占→轮转无动作） | 若 D0 仍有差 → 轮转的作用不只来自抢占，机制解释需修正 |
| **P2** | max-ITL 优势随赤字单调增大 | 若非单调或在高压下消失 → 机制有上界，如实标注区间 |
| **P3** | 轮转的「步数/下界」在所有出现抢占的压力点上都低于 native | 若某点更高 → 步效率优势不普适 |
| **P4** | 吞吐代价在所有压力点都小于重复差 | 若高压下显著变差 → 存在权衡拐点，报告该拐点 |

**我的预期是 P2 会被部分证伪**：高压下抢占频繁，轮转的强制驱逐会与原生抢占叠加，
重算成本可能压过收益。若如此，本轮给出的就是该机制的适用区间上界。

三种结局的下一步已固定：

- P2/P4 都成立 → 机制在测得区间内稳健，转入独立文档确认与写作
- P2 成立但 P4 在某点失败 → 记录权衡拐点，机制主张限定在拐点以下
- P3 失败 → 步效率不是轮转的普适优势，撤回该主张，只保留 max-ITL 结论

## 度量

完整请求 TTFT、平均 TPOT、**每请求 max-ITL**、完成延迟、恢复等待、最长排队、
episode wall、吞吐、goodput、全部失败/未完成；另记纯 decode 步数与
`步数/max(L)`、抢占与恢复事件、重算 token、逐宽度成本、峰值 KV 占用。

参考 SLO 固定 TTFT 5 s / 平均 TPOT 0.2 s，**不随结果更改**；该口径不约束最长停顿。

## 证据上限与不主张

- `REQUEST_LEVEL / NATIVE_INPROCESS_GPU_INTERVENTION`；单模型、单卡、
  一组 32 条重复文本输入、每格 n=1（重复仅正反序一对，与顺序效应混淆）。
- 不主张统计显著性、任务质量、输出一致性、Oracle/上界、HTTP 服务、多卡 EP、
  专家信号增量、公平性保证。
- **本轮只覆盖同构长输出域**；异构域已于 `20260913_heterogeneous_length_r01`
  证明会自行削平 KV 峰值而使轮转无动作，不在本轮范围。
- 轮转动作未实际触发的格记 `INVALID_NO_ACTION`，区分「无动作域」与「实现失败」，
  不解释为科学负结果。
- 只改 KV 字节，不改 N/输入/到达/cap；若某点需要改这些才能跑通，则记该点不可测。
