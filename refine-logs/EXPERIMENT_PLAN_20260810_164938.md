> 生成时间：2026-08-10 16:49 +0800  
> 状态：`FROZEN_BEFORE_IMPLEMENTATION / NOT_RUN`  
> 当前唯一实验：FrontierCredit full-DAG simulator 上的 join-closing critical/bulk split action-space Pilot

**Problem**：FrontierCredit 现有 action 只能在同一 ready expert queue 上整队 flush 或 bounded hold，把“尽快推进少量 join-closing rows”和“保留 bulk batching economy”绑成同一决策。

## 3. 冻结 CriticalSplit action

### 3.1 Join-closing partition

在每个 settled decision state，仅使用已 revealed、尚未 joined 的 physical group identity：

1. 对每个 complete top-k group，找出当前仍为 `ready` 的 blockers。
2. 只有当该 group 的全部 ready blockers 都位于同一 eligible queue 时，它们才属于该 queue 的 join-closing candidate set；其他 sibling 必须已经 running 或 completed。
3. 一个 queue 的 `critical` subset 是所有这类 blocker 的确定性并集；`bulk` 是该 queue 当前全部 ready rows 的补集。
4. 只有 `critical` 与 `bulk` 都非空时才产生 proper split；否则不制造与 whole flush 重复的 action。
5. identity-sham control 只替换为现有 revealed-prefix sham sibling mapping；不改变物理 node、queue、route、dependency 或 completion。

### 3.2 合法 action set

- `WHOLE(queue)`：旧语义，flush 该 eligible queue 的全部当前 ready rows。
- `CRITICAL(queue, sorted_node_ids)`：只 launch frozen critical subset。
- `BULK(queue, sorted_node_ids)`：只 launch frozen bulk complement。
- `HOLD`：保留原 bounded-hold legality。

Subset launch 必须：非空、无重复、严格属于一个 eligible queue；只移除被选 rows；未选 rows 保留原 `ready_since_us`；service 只按 selected rows 估算；仍独占 queue 编码的 replica；所有 downstream release 只能由原 `_settle` 完成。

## 5. Experiment Blocks

### Block B0：Transition Contract 与回归闭合

- **Claim tested**：subset action 没有改变物理 DAG、identity、hold 或 executor semantics。
- **Compared systems**：历史 whole flush wrapper；新 validated subset launch。
- **Metrics**：node conservation、ready-age preservation、service rows、busy-executor rejection、Oracle token replay equality、历史 13 tests 回归。
- **Success criterion**：全部合同测试通过；历史 FrontierCredit byte-level deterministic result仍可独立重跑。
- **Failure interpretation**：`INVALID_IMPLEMENTATION`，禁止进入 B1。
- **Priority**：MUST-RUN。

### Block B1：Actual-Identity Expanded Exact Oracle

- **Claim tested**：proper critical split 是否扩大 old whole-ready exact action space。
- **Dataset / task**：冻结 8 cells；actual revealed physical identity。
- **Compared systems**：immediate、历史 whole-ready exact Oracle、CriticalSplit expanded exact Oracle。
- **Primary metrics**：
  - `expanded_headroom = immediate_flow - split_oracle_flow`；
  - `whole_capture = (immediate_flow - whole_oracle_flow) / expanded_headroom`；
  - actual `CRITICAL` proper-subset use count；
  - deadline-miss delta。
- **Success criterion**：至少 2 个 actual eligible cells 严格 `split < whole` 且使用 `CRITICAL`；eligible-cell `whole_capture` median `<0.90`；deadline miss delta 全部 `<=0`。
- **Failure interpretation**：动作空间没有非平凡 residual，`WEAKEN_ACTION_SPACE`；停止 online controller 和 GPU 工作。
- **Priority**：MUST-RUN。

### Block B2：Identity-Sham Necessity Control

- **Claim tested**：increment 是否依赖真实 fork-join sibling identity。
- **Compared systems**：actual-identity expanded Oracle；sham-identity expanded Oracle；二者使用相同物理 state transition。
- **Primary metrics**：`sham_capture = (immediate_flow - sham_split_flow) / expanded_headroom`；`identity_gap = 1 - sham_capture`；sham-applicable eligible-cell count。
- **Success criterion**：至少 2 个 eligible cells 的 canonical action set 被 sham 改变，且 `identity_gap` median `>=0.10`。
- **Failure interpretation**：若 sham 捕获 `>=90%`，新增能力更像 generic subset scheduling，CriticalSplit 的 MoE-specific formulation 被削弱。
- **Priority**：MUST-RUN。

- **状态**：CUT FROM THIS PILOT。

## 6. 机械判定

### `SUPPORT_ACTION_SPACE`

同时满足：

1. evidence/ledger/state closure 完整；
2. actual eligible cells `>=2`；
3. 每个 eligible cell 的 expanded Oracle 实际使用至少一个 `CRITICAL` proper subset；
4. `median(whole_capture) < 0.90`；
5. sham-applicable eligible cells `>=2`；
6. `median(identity_gap) >=0.10`；
7. actual split Oracle 相对 whole Oracle不增加 deadline misses。

### `WEAKEN_ACTION_SPACE`

完整性通过，但任一支持条件不满足。特别包括：split Oracle 与 whole Oracle等价、只靠 `BULK` action、whole Oracle捕获 `>=90%`、sham捕获 `>=90%` 或 deadline misses 增加。不得修改 cells、service curve、partition predicate 或阈值救结果。

### `INVALID`

node/identity/readiness不守恒，future suffix进入 partition，subset token不能精确 replay，Oracle state cap未闭合，expanded policy优于其 exact Oracle，或输出/manifest/completion缺失。

## 9. Risks and Mitigations

- **风险：critical predicate 实际等价于 queue order。** 通过 identity-sham Oracle隔离。
- **风险：subset 只靠更多 launches取巧。** exact objective 保留 launches/total service tie-break，并报告 launch/service tax；主 gate仍要求 flow residual。
- **风险：8 synthetic cells 已被历史研究看过。** 本轮只做 development qualification，不写自然 prevalence或论文结果；正向只授权构造新的 frozen cells/trace。
- **风险：与 Gimbal/ExpertPlex 相邻。** 贡献只保留 fork-join closing subset 与 bulk batching 的非等价 action；generic deadline/expert-pressure scheduler不进入 claim。
