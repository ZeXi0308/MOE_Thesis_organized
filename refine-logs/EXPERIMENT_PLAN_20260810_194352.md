# StableBatch C8 Action-Transfer Gate 实验计划

**Problem**：fixed-C8 是否能继承 M1 single-contribution oracle 的路由恢复能力，并且收益是否依赖正确 rank。  
**Method Thesis**：只有当同一 M1-positive rank 上的 one-C8-plus-seven-M64 动作保留大部分 M1 恢复且优于 C8 exact-random rank 时，才把 ShapeABI execution primitive 与 StabilityBudget policy 合并为主线。  
**Date**：2026-08-10  
**Evidence type**：`self_supervised_proxy / M1-positive-cohort action-transfer`，不是总体无偏泛化、模型质量或 serving 结果。

## Experiment Block B1：M1-positive cohort 上的 C8 transfer

- **Compared systems**：
  - A：all-M64 no intervention；
  - B：one-M1 at frozen M1 rank + seven-M64；
  - C：one-C8 at the same frozen rank + seven-M64；
  - D：每 cell 全跑 8 个 one-C8 actions 后的 exact uniform-rank expectation；
  - E：每 cell C8 best-rank hindsight oracle；
  - F：已有 M1 八 rank ledger 的 exact uniform-rank expectation。
- **C8 action**：固定 `C=8`、D10 已测的 `zero_pad_slot5`；每 rank side-call 3 次，hash 必须稳定；除被选 rank 外其余 7 ranks 明确使用 M64，不使用 native。
- **Current-run closure**：重新执行 R、U、frozen-rank M1 作为本 Gate 的 baseline/identity closure；不重跑 240-cell M1 sweep。
- **Route mismatch unit**：intervention layer 之后 top-k membership set 与 all-M1 reference 不同的 layer；分别记录 recovered、harmed、persistent、net。
- **Final-logit unit**：bitwise element mismatch；保留可独立重算的 packed mismatch bitset，同时报告 binary hash recovery/harm，禁止把 route recovery写成 quality improvement。
- **Aggregations**：264 C8 action rows；33 unique-cell primary rows；8 个 per-document rows；8 个 leave-one-document-out rows。
- **Primary metrics**：
  - `transfer_ratio = C8_same_rank_recovered / M1_same_rank_recovered`；
  - `rank_specificity_gap = C8_same_rank_net - C8_exact_random_net`；
  - `c8_oracle_gap = C8_best_rank_net - C8_same_rank_net`。
- **Failure interpretation**：严格按用户冻结 A–E 情况；30%–70% 只允许一次机制诊断，不调 C、不开发 selector。
- **Priority**：MUST-RUN；本轮唯一实验。

## 预冻结方向判定

| Outcome | Gate | Direction |
|---|---|---|
| transfer ≥70%，same-rank > exact-random，LODO 方向一致且无大量新增 harm | GO | 合并为 `ShapeABI + StabilityBudget`；下一 Gate 才测试 outcome-naive selector |
| same-rank 有效但与 exact-random 基本相同 | CONDITIONAL | 转 global ShapeABI；下一 Gate 只测稳定性–成本 Pareto |
| transfer ≤30% | STOP ShapeLane quality mainline | 改 M1-like precision/state protection 或 WitnessPatch |
| same-rank 弱但 C8 oracle 强 | CONDITIONAL | 先做 fresh C8-specific oracle；不宣称继承 M1 action |
| same/random/oracle 均无实质恢复 | STOP | 移除 ShapeLane 主线，转 WitnessPatch 或终止 StableBatch |
| 30% < transfer <70% | CONDITIONAL | 只允许一次清晰机制分割诊断；无分割则按弱结果处理 |
