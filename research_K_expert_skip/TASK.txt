单 token 槽占比：一步 B 个 token、每 token k 个专家、专家 e 选中概率 p_e。专家 e 在本步只被一个 token 选中的概率近似 $B k p_e(1-k p_e)^{B-1}$；均匀近似下，一个槽"独占"的概率 $u(B)=(1-k/E)^{B-1}$。 OLMoE（k/E=1/8）：B=1 → 1.0；B=4 → 0.67；B=8 → 0.39；B=16 → 0.13；B=32 → 0.02。 Qwen3-30B-A3B（k/E=1/16）：B=8 → 0.64；B=16 → 0.38；B=32 → 0.13。 E=256、k=8（DeepSeek-V3 形态）：B=32 → 0.38；B=64 → 0.14。 结论：E/k 越大，跳过能省字节的 batch 范围越宽；这就是现代细粒度 MoE 给本课题的空间。
边际字节：对 (token t, 专家 e)，$c_{t,e}=w_e\cdot[\text{count}_e=1]$；本步总节省 $=\sum_{\text{skipped}} c_{t,e}$。 质量代价：$\delta(r,g)$，r 为 rank、g 为 gate 权重（重归一化后），由 W1 的 drop 表给出；每 token 预算 $m$（被丢弃的 gate 质量占比上限）。 决策：跳过 iff $r\ge r_0$ ∧ $g\le\tau$ ∧ $\text{count}_e=1$，且该 token 累计丢弃质量 ≤ m。等价于"只在跳过有收益的地方花质量预算"。对照的两条基线把质量花在无收益的地方：全局减 k（对所有 token 砍尾部）、AdapMoE 式 gate 阈值（不看 count）。 预期：OLMoE B=1 跳过尾部 4/8 → 字节 −50%、专家时间 ≈ −45%；B=8 约 −20%；B=32 ≈ 0。Qwen3-30B-A3B 同幅度后移一倍 batch。
